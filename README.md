# نجم واي فاي — Najim WiFi

تطبيق Android محلي لإدارة عهدة كروت الإنترنت والمبيعات والديون لدى المحلات، مبني باستخدام Kotlin وJetpack Compose وRoom. الواجهة عربية RTL، والتبويبات الأربعة ثابتة: **الرئيسية، الأرشيف، الإدارة، الإعدادات**.

## حقائق المحاسبة الأساسية

- تسليم الكروت يزيد عهدة المحل ولا ينشئ مبيعات أو ديونًا.
- المحاسبة تتم لباقة واحدة أو «جميع الفئات»، ويحدد المالك المتبقي الفعلي لكل باقة.
- المبلغ الجديد = المباع × سعر المحاسبة العام المحفوظ تاريخيًا للباقة.
- الدين للعميل **واحد عبر جميع الباقات**، ودفع مجموعة المحاسبة يسجل **مرة واحدة**.
- الأرشفة لا تحذف السجلات ولا تعيد إضافة العهدة أو ترحل دينًا جديدًا.
- المخزون المركزي والتنبيهات اختياريان.

## بناء APK

المتطلبات: Android SDK بمستوى 36، JDK 17، Gradle Wrapper الموجود في المشروع، والاعتمادات المحددة في ملفات Gradle. عند أول بناء تحتاج الاعتمادات إلى تنزيل من مصادرها.

```bash
./gradlew :app:assembleDebug
```

الملف الناتج، بعد البناء الناجح: `app/build/outputs/apk/debug/app-debug.apk`.

## الاختبارات

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

- اختبارات الوحدة: قواعد المبالغ والمحاسبة.
- اختبارات Android: قاعدة Room التجريبية، قيود التاريخ، الأرشفة، تشفير ملف النسخ الاحتياطي، قاعدة اختبار SQLCipher، ثبات تبويبات RTL، وإنشاء تقرير A4 متعدد الصفحات.
- قاعدة SQLCipher الخاصة بالاختبارات لها **اسم مختلف عشوائي**؛ لا تستخدم `najim_wifi.db`.
- لا يُعد اختبار تشفير ملف متعدد الإطارات بديلًا عن تجربة **استعادة كاملة على هاتف آخر**. ولم تتضمن الاختبارات الآلية الحالية محاكاة فعلية لـGoogle Drive أو قياس جودة عرض جميع أشكال الحروف العربية بصريًا أو اختبارات لمس لكل شاشة.
- Workflow في `.github/workflows/android-ci.yml` يتيح البناء واختبارات JVM والمحاكي. **وجوده لا يعني أن GitHub Actions شُغّل أو نجح**.

## العربية والخطوط

واجهة التطبيق تستخدم Tajawal؛ التقارير والإيصالات تستخدم ملفات Cairo المحلية المرفقة مع التراخيص داخل `app/src/main/assets/licenses/`. ينبغي فحص نتيجة PDF على جهاز حقيقي قبل إصدار الإنتاج.

## حماية البيانات والنسخ الاحتياطي

- حساب القفل المحلي لا يستخدم Google؛ لا تخزن كلمة مروره كنص صريح.
- القواعد **الجديدة** يمكن إنشاؤها مشفرة بـSQLCipher، أما قاعدة SQLite الموجودة سابقًا فتظل دون ترحيل تلقائي حفاظًا على البيانات.
- النسخة الاحتياطية المحمولة تستخدم عبارة استرداد مستقلة عن Android Keystore. احتفظ بها خارج الهاتف؛ فقدانها يعني عدم القدرة على فك النسخة.
- احذر من استعادة بيانات حقيقية قبل اختبار التراجع ونسخة الإنقاذ على بيئة منفصلة. الاستعادة الكاملة بين هاتفين والهجرة من SQLite إلى SQLCipher وتكامل Google OAuth تحتاج قبولًا عمليًا قبل استخدام الإصدار إنتاجيًا.
- إعداد Google Drive يتطلب OAuth مُعدًا من مالك التطبيق وتوقيع APK الصحيح؛ لا تتضمن المستودعات بيانات اعتماد جاهزة.
- لا تُرفع سجلات عملاء أو أسرار التوقيع أو قواعد بيانات حقيقية إلى GitHub.
